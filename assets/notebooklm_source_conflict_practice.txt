[교육 운영 자료 충돌 확인 실습]

아래 항목은 세 교육용 소스를 함께 읽을 때 반드시 원문을 다시 확인해야 하는 지점을 정리한 강사용 관찰표입니다.

1. 만족도 수치
- 비율만 제시됐는지, 응답 인원과 전체 인원이 함께 제시됐는지 확인
- 서로 다른 조사 시점의 수치를 하나의 추세처럼 합치지 않기

2. 교육 시간과 구성
- 기존 운영안의 확정 일정과 개선회의에서 나온 제안을 구분
- '늘리자'는 의견을 이미 확정된 시간표로 바꾸지 않기

3. 담당자와 기한
- 문서에 이름이나 날짜가 없으면 [확인 필요]로 남기기
- 일반적인 업무 관행을 근거처럼 보충하지 않기

4. 보고서 작성 후 확인
- 핵심 결론 3개의 인용을 직접 열기
- 인용 원문이 결론 전체를 지지하는지 문맥 확인
- 숫자, 담당자, 기한, 확정 표현을 우선 검증
