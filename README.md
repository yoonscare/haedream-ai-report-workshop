# 해드림엘피씨 10분 보고서 초안 실습실

생성형 AI를 활용해 현장 메모에서 검토 가능한 보고서 초안을 만드는 4시간 실습형 웹 교재 초안입니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 엽니다. 별도 설치와 서버가 필요하지 않습니다.

## 포함 기능

- 5개 학습 파트의 단계별 수업 화면(총 230분)과 진행률 브라우저 저장
- 도입 질문, 결과 비교, 강사 시연, 조별 실습, 교차검토, 미니퀴즈
- 해드림엘피씨 업무 맥락의 비식별 실습사례 4종
- 목적·독자·자료·형식·표현·안전장치 기반 프롬프트 작성기
- Gemini에 붙여 넣을 프롬프트 복사
- 10분 보고서 챌린지 타이머
- AI 초안 검토 체크리스트
- 모바일 및 인쇄/PDF 저장 대응

## 확정 후 수정할 항목

- 실제 제공 AI 도구와 계정 종류
- 교육생 부서·직급과 주 사용 보고서
- 회사의 생성형 AI 및 정보보안 기준
- 회사 공식 명칭·로고 사용 승인
- 회차별 시간과 교육 장소

현재 버전은 외부 API와 연결하지 않으며 입력 내용은 서버로 전송하지 않습니다.

## 4시간 운영

- 1부 AI와 보고서 업무: 35분
- 2부 10분 초안 공식: 55분
- 휴식: 10분
- 3부 현장 사례 실습: 55분
- 4부 초안 검토와 개선: 45분
- 5부 내 업무 적용: 40분
